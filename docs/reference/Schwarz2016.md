# Original data used by Schwarz (2016)

A dataset containing the calibrated set values for the article: Schwarz,
Oliver (2016): Two Steps Forward One Step Back: What Shapes the Process
of EU Enlargement in South-Eastern Europe? Journal of European
Integration 38 (7): 757-773.

## Usage

``` r
Schwarz2016
```

## Format

A data frame with 74 rows and 9 variables:

- Case.ID:

  Country-year ID

- enlarge:

  Progress in the EU accession process

- poltrans:

  Democracy status of the country

- ecotrans:

  Market economy status of the country

- reform:

  State of reform policy

- conflict:

  Mean conflict intensity in a country per year

- attention:

  EU’s attention to the issue of enlargement

- year:

  Year ID

- country:

  Country ID
